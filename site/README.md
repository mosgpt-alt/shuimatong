# 进出口税则 2026 · 报关速查

以 **税则号列 + 货品名称** 为主体的静态查询站。数据全部来自《中华人民共和国进出口税则（2026）》原书解析，
单文件离线可用，双击 `index.html` 就能打开，不需要联网、不需要服务器、不需要装任何东西。

- 进口税目 **8,972** 条（8 位税则号列）
- 出口税目 **107** 条
- 21 类 **96** 章完整目录
- 商品俗称（大白话）词典 **1,202** 条 / **162** 组

## 页面长什么样

参考 HS 编码类网站的通行做法：**左侧类/章树 + 主体大表格 + 右侧详情抽屉**。

| 区域 | 内容 |
|---|---|
| 主表格 | 税则号列 ｜ 货品名称（自身品名 + 完整归类路径 + 俗称标签）｜ 最惠国 ｜ 暂定 ｜ 普通 ｜ 协定 ｜ 操作 |
| 左侧树 | 21 类 → 96 章，点击即筛选 |
| 详情抽屉 | 完整归类路径、货品全称、大白话叫法、全部税率（含协定/特惠/从量税注释）、申报五要素录入、12 个外部核验网站 |

## 申报五要素

税则原文只有「编码 + 品名 + 税率」，报关真正要填的要素书里没有。详情抽屉里提供 6 个录入框：

规范申报要素 · 法定计量单位 · 监管证件 · 检验检疫类别 · 税率补充 · 备注

填完存在**你自己电脑的浏览器**里（localStorage），关机不丢、不上传任何服务器。
在「我的申报」页可以查看、搜索、导出 CSV，也能导出 JSON 备份换电脑用。

## 原始资料（`data/` 目录）

给后期做程序 / 小程序 / 接口用的结构化数据：

| 文件 | 说明 |
|---|---|
| `tariff2026_import.csv` | 进口税则全量 8,972 条，15 列，UTF-8 BOM，Excel 直接打开 |
| `tariff2026_export.csv` | 出口税则 107 条 |
| `tariff2026_alias.csv` | 俗称对照表 162 组 |
| `tariff2026_chapters.csv` | 类/章目录 96 章 |
| `tariff2026.db` | SQLite，4 张表 + FTS5 全文索引 |

SQLite 用法示例：

```sql
-- 按俗称找
SELECT code,name,mfn FROM tariff_import WHERE alias LIKE '%笔记本%';
-- 全文检索
SELECT code,name FROM tariff_fts WHERE tariff_fts MATCH '平板电脑';
-- 按章统计
SELECT ch,title,cnt FROM chapter ORDER BY cnt DESC;
```

表结构：`tariff_import(code, seq, heading, name, full_name, path, alias, mfn,
provisional, general, agreement, preferential, specific_duty, chapter, page)`

## 发布到 GitHub Pages

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

然后在仓库 **Settings → Pages → Source 选 "Deploy from a branch" → Branch 选 `main`、目录 `/ (root)` → Save**。
约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 说明

- 税率、品名以《进出口税则（2026）》原书为准；申报要素、监管证件、检验检疫、退税率**不在税则内**，
  需到海关总署「单一窗口」及各报关数据服务平台查询（详情抽屉里已带好链接，点击自动复制税号）。
- 归类结论最终以**海关现场审单或预裁定**为准，本工具仅供查询参考。
- 俗称词典是为了方便检索而人工整理的对照，**不构成归类依据**。
